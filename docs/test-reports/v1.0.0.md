# Agent Doctor v1.0.0 release evidence

Date: 2026-08-13 (Asia/Shanghai)

This report records reproducible local evidence. It does not claim that a GitHub
release exists until the tagged GitHub workflow completes successfully.

## Source verification

- `go test -json ./... -race -count=1`: 161 tests passed across 29 packages.
- `pnpm -r test --run`: 16 tests passed: dashboard 9, OpenCode adapter 3,
  verified installer 4.
- `pnpm --dir dashboard build`: production dashboard bundle built successfully.
- `./scripts/check-docs.sh`: documentation links and required public documents
  passed.
- `./scripts/check-secrets.sh`: repository secret and prohibited-data scan
  passed.
- `git diff --check`: passed.

## Local lifecycle verification

The macOS arm64 binary was built from the current source with version
`1.0.0-local` and exercised in an isolated home and configuration directory.

- setup preview returned an exact diff without changing configuration;
- setup apply added only the marked Codex MCP block;
- a second setup produced the same configuration hash and skipped the owned
  block, proving idempotence;
- doctor opened the schema-v3 SQLite store without recovery mode;
- pause and resume persisted and removed the global capture state;
- export returned aggregate summaries with event payloads excluded;
- uninstall removed only the Agent Doctor-owned block;
- forget removed the local SQLite database and sidecar files;
- `start --once --no-open` returned a random `127.0.0.1` URL;
- a persistent smoke test returned HTTP 200, `Cache-Control: no-store`, and
  `Content-Type: text/html; charset=utf-8`; `lsof` confirmed the listener was
  bound only to `127.0.0.1` before a clean interrupt.

No browser was opened during this verification.

## Dashboard coverage

The embedded React dashboard contains eight routed views backed by local,
sanitized aggregate APIs:

1. Overview
2. Task evidence
3. Costs
4. Memory
5. Comparison
6. Trends
7. Integrations
8. Privacy

The dashboard unit tests cover navigation and aggregate rendering. The
production bundle is embedded into the Go binary and the local HTTP response was
smoke-tested. Visual browser automation was intentionally not run in this
verification because the requested local workflow explicitly prohibited opening
a browser.

The Integrations view lists all eleven declared client boundaries, including
Aider, Cherry Studio, and generic CLI usage. Navigation, task actions, empty
states, trend units, and privacy controls are bilingual rather than mixing
English controls into the Chinese interface.

## Cross-platform artifacts

GoReleaser built six snapshot archives from the current source:

- macOS amd64 and arm64;
- Linux amd64 and arm64;
- Windows amd64 and arm64.

Every archive and its Syft SPDX JSON SBOM appears in `SHA256SUMS.txt` and passed
`scripts/verify-release.sh`. These are cross-build and artifact-integrity checks;
only the macOS arm64 binary received the full local runtime lifecycle test in
this environment. GitHub-hosted CI remains responsible for native runner tests
before a tagged public release.

## Compatibility boundary

Codex, Claude Code, Cline, OpenCode, Cursor, Windsurf, Roo Code, Continue,
Aider, Cherry Studio, and generic CLI tools have declared and tested capability
contracts. Automatic setup currently changes only its marked Codex MCP block.
Other integrations are provided as explicit templates, hooks, plugins, or the
safe wrapper; the tool does not silently rewrite private client configuration.

## Release gate

A public v1.0.0 release is ready for the repository/CI stage only when all of the
following are true:

- the public `18534516725/Agent-Doctor` repository exists;
- `main` contains the verified source commit;
- GitHub CI is green on the supported runner matrix;
- the signed `v1.0.0` tag workflow publishes archives, SBOMs,
  `SHA256SUMS.txt`, and `release-manifest.json`;
- the published assets are downloaded and independently re-verified.

Until those conditions hold, README installer commands remain documented as
post-release commands rather than claims of an available release.
