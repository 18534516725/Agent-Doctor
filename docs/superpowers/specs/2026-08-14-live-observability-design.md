# Agent Doctor 实时全量观测与仪表盘重构设计

日期：2026-08-14

## 目标

Agent Doctor 下载并启动后，应自动识别当前用户已安装的 AI 编程客户端，在不破坏原配置的前提下完成可验证接入，并立即开始记录后续任务。用户在本地仪表盘中实时查看完整对话、工具调用、文件与测试事件、Token、费用、延迟、上下文和诊断结果。

基础分析不调用额外模型，也不要求单独提供分析 API Key。它只使用当前编辑器与当前模型交互时已经产生的请求、响应、计费和生命周期证据。

## 产品原则

1. 数据属于当前操作系统用户，默认不离开设备。
2. 完整保存对话正文，但永不保存 API Key、Cookie、Authorization 请求头或其他认证凭证。
3. 不绕过客户端权限，不读取私有客户端数据库，不通过屏幕抓取对话。
4. 缺少客户端公开接口时明确显示能力限制，不伪造完整支持。
5. 所有自动配置都可预览、可重复执行、先备份、失败回滚、可完整卸载。
6. 统计与诊断区分精确、估算和不可用，不能把缺失数据显示成零。

## 总体架构

```text
AI 编程客户端
  ├─ OpenAI/Anthropic 兼容请求 ──> 127.0.0.1 本地透明代理 ──> 用户原配置的 API 服务
  │                                      │
  │                                      ├─ 完整消息与流式增量
  │                                      ├─ Token、模型、延迟、状态码
  │                                      └─ 凭证仅内存转发，不落盘
  │
  └─ 官方 Hooks / 插件 / 包装器 ──> 工具、文件、测试与任务生命周期
                                         │
                                         v
                  事件规范化与凭证字段过滤 ──> 本地 SQLite
                                                   │
                                      聚合 API + SSE 实时事件流
                                                   │
                                           React 本地仪表盘
```

本地代理和仪表盘使用同一个 Go 进程，但监听职责分离。仪表盘继续使用随机回环端口和随机会话令牌；代理只绑定 `127.0.0.1`，不会监听局域网或公网地址。

## 启动与自动接入

`agent-doctor start --no-open` 的启动顺序：

1. 获取单实例锁，打开本地数据库并完成迁移。
2. 检测 Codex、Claude Code、Cursor、Cline、OpenCode、Windsurf、Roo Code、Continue、Aider、Cherry Studio 和通用 CLI 能力。
3. 为具有公开、稳定配置格式且已检测到的客户端生成接入计划。
4. 对此前已经授权过自动接入的客户端执行幂等配置；首次源代码运行在终端输出精确计划，正式安装器在安装确认中包含该授权。
5. 修改前创建用户私有备份，任一步失败则回滚本轮全部修改。
6. 启动本地代理、事件处理器、SSE Hub 和仪表盘。
7. 页面立即展示客户端为“已连接”“仅事件”“等待重启”“需要手动接入”或“未检测到”。

不能安全自动配置的客户端不被强行修改。其集成卡提供复制配置或执行受控一键接入的入口，并明确解释缺少的能力。

## 本地代理

代理支持 OpenAI Responses、Chat Completions 和 Anthropic Messages 的普通与流式请求。它保持请求方法、路径、查询参数、响应状态和流式语义，不改变模型结果。

每次请求生成本地会话与请求 ID，保存：

- 客户端、项目、模型和协议；
- system、user、assistant、tool 消息的完整正文；
- 工具调用名称、参数和结果；
- 输入、输出、缓存和推理 Token（响应提供时为精确值）；
- 首字延迟、总耗时、状态、重试和错误分类；
- 当前价格目录版本、费用精度和金额。

代理绝不持久化认证头、Cookie、API Key、完整请求头集合或代理环境凭证。传输凭证仅在当前请求内存中使用，完成转发后释放。

对于客户端不允许配置代理或不公开消息事件的情况，只保存 Hooks 能提供的生命周期证据，页面必须显示“对话不可用”。

## 存储与访问控制

新增会话消息、流式片段、客户端连接和实时分析表。数据库文件、WAL、备份与本地配置保持当前用户私有权限。

完整正文只通过带会话令牌的 loopback API 返回。服务拒绝非回环连接、外部 Origin、跨站请求和 iframe 嵌入。日志、CLI 默认输出、崩溃信息和导出摘要不得包含对话正文或凭证。

隐私页提供：

- 暂停/恢复全部采集；
- 完整对话采集开关；安装授权后默认开启，用户可随时暂停；
- 保留天数；
- 删除单个会话；
- 按项目删除；
- 清除所有本地数据；
- 导出完整本地数据或仅聚合数据，两者明确区分。

## 实时数据流

客户端或代理写入事件后，在同一事务提交成功后向 SSE Hub 发布轻量变更通知。浏览器收到通知后只请求受影响的会话或聚合数据，不重复下载全部历史。

SSE 包含心跳、递增事件序号和断线重连游标。页面断线时显示状态并指数退避重连；恢复后从最后序号补齐，若游标过期则重新读取当前快照。

## 分析数据

不使用额外模型的本地分析包括：

- 当前会话输入、输出、缓存、推理与总 Token；
- 精确费用、目录估算费用和不可用费用；
- 上下文使用量与逼近限制的趋势；
- 首字延迟、总耗时、流式速度和错误率；
- 工具调用次数、成功率、耗时和连续失败；
- 文件修改、测试运行与测试结果；
- 重复提示、重复工具调用和可能的循环；
- 会话阶段、活跃时间和最后事件；
- 同项目、同任务类型、同主要版本的历史基线比较。

诊断规则只引用存在的事件，并在结果中列出证据、精度、限制和建议。可选的模型深度分析属于后续独立功能，默认关闭且不影响上述功能。

## 仪表盘视觉与交互

视觉方向采用“精密观测仪器”，而不是传统后台或霓虹 AI 面板。使用暖灰纸面、深墨绿和单一荧光黄绿信号色，搭配清晰的编辑字体层级、细网格、刻度与状态轨迹。

首屏分为：

- 顶部运行状态条：监听中、数据仅在本机、连接客户端数量、当前任务；
- 左侧稳定导航；
- 主区域当前任务脉冲视图；
- 右侧实时编辑器连接轨与费用/Token 累计；
- 下方滚动对话与工具事件时间线。

八个页面调整为：

1. 实时总览：当前任务、实时指标、最近异常和编辑器连接。
2. 对话与证据：完整消息、工具调用、文件与测试时间线。
3. Token 与费用：精度分层、模型/项目/日期拆分和预算趋势。
4. 项目记忆：候选、启用、停用和来源会话。
5. 对比实验：匹配样本、差异和可信限制。
6. 趋势：延迟、错误、Token、费用和工具效率。
7. 集成：每个客户端的检测、连接、消息、工具和费用能力。
8. 隐私与数据：采集范围、保留、导出和删除。

默认语言为中文；用户主动切换 English 后将选择保存在本地。页面加载、路由切换、实时事件追加和连接状态变化使用短促的 transform/opacity 动效；遵守 `prefers-reduced-motion`。

空状态不再显示四个无解释的零。它展示检测中的客户端、连接进度、监听状态和第一条真实事件如何产生。

## 错误处理

- 单个客户端配置失败不阻止其他客户端和仪表盘启动。
- 代理转发失败保持原始 HTTP/流式错误语义，但持久化和页面只展示安全分类。
- 数据库只读恢复模式仍允许浏览已有数据，并停止新采集。
- SSE 失败降级为定时增量拉取。
- 价格未知时费用显示不可用，不使用默认价格猜测。
- 客户端需要重启时显示明确状态，不宣称已经开始捕获。

## 测试策略

1. 单元测试：协议解析、流式重组、凭证不落盘、Token/费用精度、连接状态和 SSE 游标。
2. 安装测试：检测、备份、幂等、冲突、回滚、卸载和不同操作系统路径。
3. 代理集成测试：OpenAI/Anthropic 普通与流式转发，客户端断开、服务端错误和取消请求。
4. 存储测试：完整消息持久化、删除范围、保留期和迁移恢复。
5. 仪表盘测试：中文默认、八页、实时更新、完整消息、连接状态、空状态、错误重连和隐私控制。
6. 安全测试：只监听回环、会话令牌、Origin、CSP、凭证字段扫描、日志和导出边界。
7. 发布测试：macOS/Windows/Linux 的构建、SBOM、校验和以及原生运行器验证。

实现过程不打开浏览器；自动化 DOM 测试、构建和 HTTP/SSE 测试完成后，由用户自行打开本地地址进行视觉验收。

## 明确限制

- 已经在 Agent Doctor 启动前发生的对话不会被补抓。
- 客户端必须允许公开 Hook、插件或自定义 API 地址，才能获得对应数据。
- 配置完成但必须重启的编辑器，在重启前不能宣称实时捕获。
- 操作系统管理员仍可读取当前用户文件；“仅用户可见”指普通本地账户权限和应用访问边界，不是抵御已取得管理员权限的攻击者。
- 本地规则分析不等同于模型推理，不会在缺少证据时生成主观结论。
