# Safe public-beta feedback

Choose the matching form at <https://github.com/18534516725/Agent-Doctor/issues/new/choose>.

Include:

- operating system and architecture;
- Agent Doctor and client versions;
- exact startup command with secrets replaced;
- minimal reproducible steps;
- expected and actual behavior;
- whether the result changes after a clean new session.

Never attach a complete SQLite database, complete conversation, API key, Authorization header, Cookie, private source file, private path listing or raw transport dump. Security reports belong in the private channel described in `SECURITY.md`.
