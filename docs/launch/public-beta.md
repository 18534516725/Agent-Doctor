# Agent Doctor public beta

Agent Doctor is an open-source local evidence and guidance layer for AI coding tasks, maintained by NexoToken.

The beta is intended for real-project validation. It is not a claim that every editor exposes the same data or that guidance can always block an agent. Public claims must remain traceable to tests, the compatibility matrix and release artifacts.

## What is ready

- local SQLite evidence and a loopback-only dashboard;
- deterministic analysis without a second model API key;
- Codex MCP/Skill and Claude Code Hook paths;
- exact, estimated and unavailable cost states;
- bounded cross-client handoff and local delivery receipts;
- safe pause, export, forget and uninstall controls.

## What feedback helps

Client/version compatibility, misleading analysis, incorrect precision labels, installation failures and confusing first-run states. Use the issue chooser and follow the feedback guide.
