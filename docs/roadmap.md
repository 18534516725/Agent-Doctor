# Public roadmap

The roadmap is driven by reproducible evidence, not vote counts alone.

## Public beta

- validate installation on macOS, Linux and Windows runners and real devices;
- improve Codex and Claude Code connection explanations and first-run states;
- expand analysis cards without turning raw transcripts into the primary UI;
- verify cost catalogs and optional NexoToken personal-usage import;
- collect client/version-specific compatibility reports.

## After beta evidence

- richer task baselines once matched cohorts reach the documented minimum;
- additional documented lifecycle adapters where clients expose stable APIs;
- signed/notarized desktop packaging when release evidence supports it;
- opt-in sanitized diagnostic bundles that never include conversations or credentials.

No roadmap item is a delivery promise. Track accepted work through GitHub issues and releases.
