# Changelog

All notable changes are documented here. Agent Doctor follows semantic versioning after the first stable release.

## [0.1.0-beta.1] - 2026-08-16

### Added

- local loopback dashboard with task, conversation, cost, memory, comparison, trend, integration and privacy views;
- SQLite-backed normalized evidence and complete local conversation timeline;
- deterministic runtime guidance with provenance, precision and limitations;
- Codex MCP/Skill integration, Claude Code Hook integration and safe CLI wrapper;
- cross-client bounded task handoff with delivery receipts;
- exact, estimated and unavailable cost states;
- bilingual repository onboarding and safe public feedback workflow.

### Known limitations

- live capture requires starting a new client through the wrapper;
- capability depth varies by documented client interface;
- public beta compatibility feedback is still being collected.
